# Шрифты

Остров рисуется шрифтом **SF Pro**. При сборке все `*.otf` и `*.ttf` из этой папки встраиваются в exe, поэтому вид не зависит от шрифтов, установленных в системе.

Иконки острова — тоже из SF Pro: в шрифте есть символы SF Symbols (коды `U+100000` и дальше), и `Icon.cs` берёт их контуры из `SF Pro Text` начертания Medium. Имена символов у шрифта не записаны, поэтому в `Icon.cs` рядом с кодом стоит имя символа из приложения SF Symbols. Семь значков — край, шрифт, буфер, микрофон, пульс, телефон и урна — остров по-прежнему рисует сам: они придуманы под его страницы, а не взяты у символа шрифта.

SF Pro принадлежит Apple и распространяется на условиях её лицензии ([developer.apple.com/fonts](https://developer.apple.com/fonts/)); лицензия этого репозитория на файлы шрифта не распространяется.

Если убрать файлы отсюда, текст будет рисоваться `Segoe UI Variable` (или `Segoe UI`), а из иконок останутся только те семь, что остров рисует сам.
